Obstacle Avoidance FSM Lab

A rover reads an ultrasonic sensor and runs a three-state machine: FORWARD, REVERSE, TURN. Move the obstacles, change the threshold and timings, and watch the state, the diagram and the code change together.

What is this?A robot drives FORWARD until its distance sensor sees something closer than the threshold, then it backs up (REVERSE), turns to a new direction (TURN) and drives FORWARD again; a finite state machine is the code that tracks which of those three states it is in.

    Why use an FSM?

    Nested if-else with flags

    • Two flags and two timers. The state is hidden in flag combinations.
    • Both flags can end up true by mistake.
    • Adding a SCAN or STOP behaviour means editing every branch.

    FSM with one state variable

    • One variable and one timer. Exactly one state is active.
    • Each case holds only its own action and its own exit.
    • Adding a behaviour means adding one more case.
